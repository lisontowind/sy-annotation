# 标注大纲 · Annotation Outline

**让标注，成为有结构的回顾。**

标注大纲是一个思源笔记桌面端插件。它把当前文档中的高亮、文字颜色与划线，按标题层级整理到侧栏。阅读时随手标注，回顾时沿着章节找到重点，点击卡片就能跳回原文。

![标注大纲：按章节回顾原文中的重点](https://cdn.jsdelivr.net/gh/lisontowind/sy-annotation@0.4.1/docs/assets/overview.png)

> 展示图来自思源 3.8.10 的独立测试工作空间，使用真实编辑器、原生主题及专门创建的示例文档；截图采用桌面浏览器界面。实际外观随思源版本和主题变化。介绍图片通过固定版本的 GitHub 链接加载，需要联网查看。

## 阅读、标注、回顾，在同一篇文档里

- **按章节汇总**：自动按 H1–H6 组织标注，可折叠、搜索、按样式筛选，点击跳转原文。
- **单次或连续划选**：一次标注一处，或开启连续模式后反复划选；高亮、下划线、波浪线与自定义组合样式都能使用。
- **保留原文外观**：卡片呈现文字颜色、背景色和划线等效果，方便区分不同类型的重点。
- **跟上阅读位置**：单击准星定位当前位置附近的标注，双击锁定自动跟随，再次双击解除。
- **组合筛选**：按工具特征、完整样式、颜色、划线、排版效果和标题章节组合条件，支持“并且 / 或者”、排除与嵌套分组。
- **预览后改样式**：右键卡片快速替换；也可批量处理全文或当前筛选结果，先看命中数量和前后效果，再确认修改。

适合阅读摘记、资料梳理和长文复习。插件汇总的是**当前文档**中的文字标注，不扫描整个笔记本或工作空间。

## 1. 选一个样式，开始标注

打开文档，再打开右侧「标注大纲」侧栏。在工具区选择样式，然后选择自己的标注方式：

- **标注一次**：有选中文字时，点击「标注」立即应用；没有选区时，点击后再划选一处，完成后自动退出。
- **连续标注**：点击「连续标注」，随后每次划选都会应用当前样式。过程中可以切换样式；按 `Esc` 或点击「结束标注」退出。

选择样式本身只切换工具，不改写已有选区，也不自动开启连续标注。侧栏右上角的画笔按钮可显示浮动工具栏，思源顶栏按钮和快捷键也可切换显示。

![使用步骤一：选择样式，单次标注或连续划选](https://cdn.jsdelivr.net/gh/lisontowind/sy-annotation@0.4.1/docs/assets/usage-01-annotate.png)

## 2. 沿着标题，回顾你的重点

标注会自动归入所在章节；没有标注的标题分支不显示。点击卡片跳回原文，在搜索框中输入标注内容或标题关键词，也可以结合快捷样式筛选缩小范围。

单击准星按钮定位当前位置：光标在标注内时定位到对应卡片，否则寻找同章节附近的标注。双击准星锁定自动跟随，再次双击解除。若目标被筛选隐藏，插件会提示清除筛选，不会自行修改条件。

![使用步骤二：按标题回顾、搜索与定位标注](https://cdn.jsdelivr.net/gh/lisontowind/sy-annotation@0.4.1/docs/assets/usage-02-outline.png)

## 3. 先筛出目标，再统一改样式

在「更多筛选」中添加条件或分组。例如，把“黄色高亮”与“绿色高亮”放在“或者”组中，再结合章节、文字搜索或排除条件筛出需要的标注。应用前可查看命中数量。

需要统一样式时，点击「批量改样式」，选择源样式、目标工具、替换模式和修改范围。检查前后预览与实际修改数量，再确认执行。

- **完全采用目标样式**：使用目标工具的标注格式。
- **保留额外格式**：替换颜色、划线等标注效果，保留原有加粗、斜体、上下标及字体字号；目标工具明确设置的属性优先。

也可以右键单张卡片快速改样式，或选择「批量修改相同样式」预填完整源样式。整批修改作为一次思源原生撤销操作。准备和校验期间可以取消；保存开始后请等待完成，数量较多时需要更长时间。

![使用步骤三：组合筛选与批量修改前后预览](https://cdn.jsdelivr.net/gh/lisontowind/sy-annotation@0.4.1/docs/assets/usage-03-filter-batch.png)

## 4. 同步思源样式，补充组合工具

侧栏和浮动工具栏按思源原生面板分为「最近使用、样式、文字颜色、背景颜色、文字效果」，同步思源自定义样式、排列顺序、隐藏状态和浅深配色。样式统一在思源中管理；在思源另选样式不会切换插件当前选中的标注样式。

「样式、文字颜色、背景颜色」分组首项提供原生「默认」，恢复对应配色；分组末尾的齿轮直接打开思源颜色管理。关闭管理面板后会返回原来的筛选或批量面板，并保留尚未应用的设置。

展开样式面板后，「组合工具」以紧凑的样式预览方格排列，悬停可查看名称。分组末尾的齿轮打开工具设置，可在其中新建工具，调整名称、顺序、原生配色与波浪线、加粗等组合效果。

选中正文中样式一致的文字，点击「组合工具」区的「＋」，即可按选中文本的颜色和文字效果新建组合样式，保留原生颜色引用和浅深配色，再调整名称和效果后保存。选择原生样式只改变插件选择，点击「标注」或开启「连续标注」后才会写入正文。

**组合工具的名称和效果只影响后续操作。** 修改思源原生配色时，所有关联该样式的文字会随之改变外观，正文内容无需改写。需要替换历史样式引用时，使用卡片替换或批量修改；插件卸载后已保存的格式仍然保留。

![使用步骤四：管理工具与组合标注样式](https://cdn.jsdelivr.net/gh/lisontowind/sy-annotation@0.4.1/docs/assets/usage-04-tools.png)

## 原生样式查找与深浅色

「按样式查找」与「更多筛选」使用同一份思源样式库。原生样式按引用编号或 ID 匹配，区分同色的不同样式；旧固定色可用「文字颜色／背景颜色」或「完整样式」按外观查找。文字搜索仍检索当前文档的标注内容和标题，与样式、章节条件共同生效；结果计数、点击定位和当前筛选范围的批量修改使用同一命中集合。

正文、预览、侧栏和筛选跟随思源配色与浅深模式。原生样式改名、改色、排序、隐藏或删除后自动同步；插件独立记住当前选择。隐藏只改变候选展示；当前原生样式被删除时停止标注并提示重选。同步失败时保留上次样式并提供重试；旧宿主缺少样式库接口时使用内置样式并提示升级。

原有固定色和浅深色表达式继续保留。工具设置底部「旧样式迁移 → 修复旧颜色」可将旧工具或当前文档的颜色明确关联到思源原生颜色。勾选、预览并确认后才会转换，包含未加载标注，正文可一次撤销；工具修复前保留最近一次备份，可恢复。

## 安装与兼容

**当前版本：0.4.4。** 最低声明版本为思源 3.2.0；原生标注、颜色管理与恢复默认配色已在思源 3.8.10 的独立工作空间中验证。中英文展示图来自该独立思源空间。旧版缺少原生样式库接口时使用内置样式并提示升级。

**支持中文和英文界面。** 跟随思源的界面语言显示；切换思源语言并按思源提示重启后生效。侧栏、工具栏、筛选、批量修改、工具设置和操作提示均已提供英文。自定义工具名称与笔记内容保留原文。

支持思源桌面端、桌面浏览器端与桌面独立窗口；独立窗口的侧栏挂载能力由思源决定。移动端和 PDF 画布标注不在本版本范围。跨设备同步、第三方主题及多窗口组合仍需结合实际环境测试。

可在「设置 → 集市 → 插件」中搜索「标注大纲」安装、启用。手动安装时：

1. 解压发行附件 `package.zip`，将内容放入工作空间的 `data/plugins/sy-annotation/`。
2. 确保 `plugin.json`、`index.js`、`index-worker.js`、`index.css` 直接位于插件目录下。
3. 在「设置 → 集市 → 已下载 → 插件」中启用。升级前先停用，覆盖文件后再启用。

工具配置保存在 `data/storage/petal/sy-annotation/tools.json`。连续标注和自动跟随不会在重启后自动开启。

## 使用前了解

- 处理当前文档的可编辑文字。代码块、HTML 块、嵌入块、数据库、行内公式及只读内容不接受标注。
- 仅加粗或斜体的普通文字默认不收录；与自定义工具匹配的组合、文字颜色、背景色及划线等可识别格式会收录。
- 同一正文块内连续且标注样式一致的片段合并，行内备注、链接、块引用和局部上下标不会拆分条目；夹在相同样式片段之间、未单独着色的链接、块引用及上下标也归入整段，原有内容、身份与作用范围保留。颜色、加粗、字号等其他格式差异、普通未标注文字和跨块边界仍分开处理。侧栏统计的是实际标注片段，不一定等于操作次数。
- 不依赖额外的标注服务；插件通过思源接口读取当前文档并保存原生文字格式。
