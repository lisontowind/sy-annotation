# 标注大纲 · 开发与验证说明

## 0.3.8 更新

新增中英文界面和配套集市材料。界面语言由 `src/i18n.ts` 读取思源 `window.siyuan.config.lang`；中文标签为回退文本，英文消息位于 `i18n/en_US.json`，编译时打入主入口与 Worker。Worker 请求显式传递当前语言。语言变化按思源提示重启后生效，自定义工具名称与正文不参与翻译。

`npm run assets:marketplace` 从端口 6917 的真实思源独立验收空间生成中英文封面、总览与使用图；执行前会校验工作空间路径只能是 `artifacts/acceptance-0.2.0/workspace`。示例文档、语言与原生主题通过思源 API 配置，连续标注写入后读取原文核对。截图前通过关闭按钮收起通知。`npm run assets:marketplace:demo` 仍可生成演示宿主版本供开发调试。`node scripts/marketplace-review.mjs --serve` 生成并展示本地检查页，刷新即可读取最新预览文件。图标的内置 image_gen 提示词与透明原图保存在 `docs/marketplace/`，不会打入安装包。

`npm run package` 包含类型检查、39 项单元测试、构建及文档资源校验，输出 `artifacts/sy-annotation-0.3.8.zip` 和集市附件名 `artifacts/package.zip`。`npm run test:browser` 额外覆盖英文侧栏、连续标注、Worker 查询、筛选、批量保存/撤销、工具保存和语言切换时名称保留。

0.3.8 的界面与交互通过演示宿主浏览器测试，并已在真实思源独立空间完成中英文截图及连续标注保存、搜索、筛选、批量预览与工具设置检查。以下长文原生编辑器和性能说明承接 0.3.7 及更早版本的验证记录，本次未重跑整套长文原生验收，也未修改日常思源工作空间。

## 功能与此前验证记录

思源笔记桌面端插件：按标题层级回顾当前文档的标注，支持单次及连续划选标注。

## 使用

- **选择样式**：点击样式工具只选择样式，不改写已有选区，不自动开始连续标注。
- **标注一次**：有选中文字时点击「标注」立即应用；没有有效选区时，点击后等待下一次划选，成功标注一处后自动退出。等待期间显示提示，按 Esc 可取消。
- **连续标注**：单独点击「连续标注」后，每次划选继续标注；选择其他样式只切换后续使用的样式。按 Esc 或「结束标注」退出。单次及连续状态都使用 I 形文本光标加刷子的光标。
- **显示工具栏**：点击侧栏右上角的画笔按钮可显示浮动工具栏，多次点击不会重复创建；也可使用思源顶栏按钮或快捷键切换。
- **浏览工具**：样式较多时，在工具区域滚动鼠标滚轮、触控板横滑或按住鼠标左右拖动，不显示横向或纵向滚动条。拖动不会选中工具或触发标注。
- **侧栏汇总**：点击右侧「标注大纲」图标。卡片正文显示原文的高亮、文字颜色、划线、波浪线及组合效果，保留紧凑字号。左侧色条上半段取文字颜色，下半段取背景颜色，中间渐变；缺少的颜色用灰色。按 H1–H6 标题组织，可折叠、搜索、筛选与点击跳转，无标注的标题分支不显示。
- **定位当前位置**：单击侧栏准星按钮，将侧栏滚动到光标所在的标注；光标不在标注里时，仍定位同章节附近的标注。只有当前位置实际落在标注文字内时，才显示对应卡片的选中框；离开标注会清除选中框。滚动阅读后按正文可视位置定位，同一长段落内也可区分位置，无标题文档同样支持。双击锁定自动跟随，图标变成锁；再次双击解除。锁定状态重启后关闭。
- **管理工具**：点击工具栏「＋」新建，思源原生齿轮图标打开设置；右键工具也可编辑或删除。设置中可以调整顺序、名称、文字颜色、背景颜色及组合效果，实时查看预览。卡片色条由原文样式自动生成。
- **继承当前样式**：新建或编辑时勾选「继承思源当前使用的一个样式」。仅复制思源文字样式面板最近选择的那一个样式，解析当前生效的颜色和效果后保存为独立副本；不批量复制其他预设，也不从正文选区取样。若当前操作是清除格式，请先在思源面板选择有效样式。
- **组合效果**：支持前景色、背景色、高亮、加粗、斜体、下划线、波浪线、点线、虚线、双线、删除线、上下标、阴影和空心。组合标注通过思源原生批量事务写入，跨多个普通正文块也可一次撤销。保留链接、引用及未被工具修改的格式。
- **组合筛选**：「更多筛选」可添加条件和嵌套分组，选择“并且／或者”和匹配／排除。支持工具特征、完整样式、文字色、背景色、划线、排版效果和标题章节（包含子章节），预览命中数后应用；与快捷样式和文字搜索共同生效。颜色可选择“未设置”。各文档的筛选在本次会话内保留，重启重置。
- **快速改样式**：右键卡片，选择目标工具。默认“完全采用目标样式”，也可选“保留额外格式”：替换颜色、高亮、划线、删除线、阴影和空心，保留原有加粗、斜体、上下标及字体字号；目标工具明确设置的属性优先。操作不启动连续标注，模式在本次会话内记忆。
- **批量改样式**：筛选区打开批量面板，选择源样式、目标工具、替换模式，以及全文／当前筛选结果。按工具特征匹配可包含额外效果；按完整样式精确区分组合。右键卡片的「批量修改相同样式」直接预填完整样式。预览显示命中数、实际修改数及前后效果，确认后整批作为一次原生撤销操作。

标注依据原文实际样式，不绑定创建它的工具。修改或删除工具不会改变历史原文。工具设置列表与卡片使用相同的文字色／背景色渐变条，编辑时即时预览。

默认提供四色高亮、下划线和红色波浪线。修改或删除工具只影响后续操作，不改写历史原文；删除正在使用的工具会退出连续标注。清除历史格式请使用思源原生格式工具。插件卸载后已保存的文字格式仍然保留。

同色但文字装饰不同的标注分开显示；相邻且实际格式一致的片段合并。无法匹配现有工具的历史标注仍保留原文的实际样式。快捷筛选按实际特征匹配，一处组合标注可以符合多个工具。搜索和样式筛选会显示相关分支，不受普通浏览时的折叠状态阻挡。

搜索或筛选隐藏目标标注时，定位会提示清除筛选；不会自动更改条件。定位会展开目标标注所在的折叠标题。当前位置没有标注时，按正文块距离选择同章节附近的标注（距离相同时优先后方，同一块内按文字距离）；当前章节没有标注时，沿祖先章节查找，没有相关分支时给出提示。标题前的正文在「文档开头」内定位。

## 长文处理

首次打开文档读取全文，交给独立 Worker 建立标题、块顺序和标注索引。侧栏只挂载可见行和上下各八行缓冲，按真实行高维护滚动位置；数量与搜索基于完整索引。

普通编辑、标注、撤销、重做及可识别的结构事务更新相关块或子树；标题插入、删除、移动和级别变化会修正标注归属。未识别的事务、同步重载、属性变更及手动刷新会回退到完整重建。切换文档会取消旧请求及索引任务，更新时尽量保持侧栏阅读位置。

普通段落的文字或格式编辑采用块级差量：Worker 只解析发生变化的叶子块，返回相关标注的变化，不传输整篇索引。没有影响标注的普通输入不重建侧栏；有变化时复用其余卡片 DOM，仅更新受影响行。搜索及样式筛选缓存已解析的属性，自动跟随在目标标注未变时不重复构建和滚动列表，同章节内移动只更新当前卡片的提示和侧栏滚动位置。

正文中尚未加载或折叠的块由思源原生导航加载，插件不强制将正文全文挂载到编辑器。

批量替换从全文索引选择标注，少量修改读取受影响块；涉及 32 个块及以上时，每个阶段只读取一份文档快照，避免为每个块重复载入整篇文档。在脱离正文的 DOM 中拆分边界、清理旧样式并生成新内容，不强制挂载正文。准备和校验阶段可取消，提交前再次检查原文、文档和工具；过期预览需要重新生成，不通过相同文字猜测新位置。提交期间禁止重复操作，整批只发送一个原生事务；后续仅增量更新索引。无实际变化不创建撤销记录。

批量面板显示准备、校验、保存、确认保存各阶段的数量与进度条，持续更新已用时间。思源原生保存是一次整批事务，处理中显示等待动画与时间；只有实际核对保存结果后才增加完成数量。数千处标注仍需等待内核写入，保存中不能取消。

## 安装和升级

已在 **思源 3.8.10** 的真实编辑器中验证。声明最低版本为 3.2.0；旧版缺少的样式读取能力会显示错误提示。面向桌面端、桌面浏览器端与桌面独立窗口；独立窗口的侧栏挂载能力由思源自身决定。移动端和 PDF 画布标注不在本版本范围。

1. 解压 `artifacts/sy-annotation-0.3.7.zip`，将内容放到工作空间的 `data/plugins/sy-annotation/`。
2. 确保 `plugin.json`、`index.js`、`index-worker.js` 和 `index.css` 都直接位于插件目录下。
3. 在「设置 → 集市 → 已下载 → 插件」中启用「标注大纲」。升级时先停用，覆盖文件后再启用。

工具配置保存在 `data/storage/petal/sy-annotation/tools.json`。首次升级自动迁移旧版所选工具并保留原有五个工具，额外提供波浪线工具。旧 `preferences.json` 不删除。连续标注和自动跟随均不在重启后自动开启。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 显示 / 隐藏浮动工具栏 | Alt + Shift + H | Option + Shift + H |
| 开启 / 结束连续标注 | Ctrl + Alt + H | Cmd + Option + H |
| 使用当前工具标注一次 | Alt + Shift + M | Option + Shift + M |
| 退出连续标注 | Esc | Esc |

## 开发与验证

需要 Node.js 20+。

```sh
npm install
npm run typecheck
npm test
npm run test:browser
npm run package
```

- `npm run dev`：监听 TypeScript 和样式变化，输出至 `dist/`，包含独立索引 Worker。
- `npm run preview`：在 `http://127.0.0.1:4173` 查看真实插件界面的模拟宿主预览。
- `npm test`：验证标题树、组合样式、配置迁移、选区保护、跨块原生批量接口、增量结构变更及 10,000 段 / 3,000 标注索引。
- `npm run test:browser`：使用本机 Edge（可设置 `PLAYWRIGHT_CHANNEL=chrome`）测试原有交互，以及嵌套筛选、两种替换模式、过期预览、全文与筛选范围、10,000 块／3,000 标注在正文仅挂载 12 块时的整批撤销重做。截图位于 `test-results/`。
- `npm run test:perf`：使用 20,000 个正文块、10,000 处标注验证输入、卡片复用、滚动和自动跟随，要求普通输入不重建侧栏、叶子块编辑不回传完整索引；结果保存在 `test-results/sidebar-perf-optimized.json`。
- `node scripts/native-sidebar-perf.mjs`：在同一独立验收内核中使用真实键盘输入，检查普通文字和标注文字的更新、撤销重做及全文搜索；基线比较使用 `--baseline`（仅接受本机仍安装 0.3.1 时读取旧插件副本）。
- `npm run test:native`：连接端口 6917 的独立思源验收内核，工作空间必须位于 `artifacts/acceptance-0.2.0/workspace`。验证组合样式落盘、原生增量广播、单条替换、10,000 块／3,000 标注含未加载块的批量事务、整批一次撤销重做及重开保留。此脚本不连接日常使用的 6806 端口。
- `npm run package`：执行类型检查与单元测试，构建并验证 CommonJS 入口与 Worker 文件后生成 ZIP。

本次在思源 3.8.10 独立工作空间的真实编辑器中完成了原生保存、撤销/重做和刷新保留验收；跨设备同步、第三方主题及多窗口组合仍需结合实际环境测试。

## 边界与接口

- 仅汇总当前文档，不扫描全部工作空间或笔记本。
- 代码块、HTML 块、嵌入块、数据库、行内公式、不可编辑区域和只读内容不接受标注。
- 仅加粗或斜体的普通文字不会默认收录；与自定义工具匹配的组合、文字颜色、背景色和划线等可识别格式会收录。
- 默认工具使用思源主题变量；从当前样式继承的工具保存当前外观的独立值，不随原预设变化。
- 「本次 N 处」表示标注操作次数；侧栏统计实际格式片段数，合并、组合差异或撤销时可能不同。

主要代码：`src/index.ts` 管理生命周期和增量调度；`src/editor.ts` 通过原生批量事务应用组合样式；`src/index-worker.ts` 与 `src/model.ts` 维护全文索引；`src/ui.ts`、`src/virtual-list.ts` 和 `src/tool-manager.ts` 实现界面。
